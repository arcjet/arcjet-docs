## Support policy

We provide technical support for all Arcjet users.

- **Email:** [support@arcjet.com](mailto:support@arcjet.com).
- **Discord:** [Join](https://arcjet.com/discord).
- **Slack:** [Email us](mailto:support@arcjet.com) and we'll spin up a private,
  shared channel.

### SDK lifecycle

| Arcjet SDK version     | Support          | Bug fixes | Security fixes |
| ---------------------- | ---------------- | --------- | -------------- |
| Latest major release   | All plans        | ✅        | ✅             |
| Previous major release | Enterprise plans | 🚫        | ✅             |
| Older releases         | 🚫               | 🚫        | 🚫             |
