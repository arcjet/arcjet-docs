sensitive information such as personally identifiable information (PII) that
you do not wish to handle.

### 3. Protect a route

Create a sensitive info detection rule that scans untrusted text before you
process it. HTTP adapters can use the on-device <Link.Page href="/sensitive-info/reference#on-device-detection-with-rampart">Rampart backend</Link.Page>.
Agent integrations use `localDetectSensitiveInfo` from the Guard SDK. You can
change which entity types to detect. For details, see the
<Link.Page href="/sensitive-info/reference">reference</Link.Page>.

Your logs show this

```text
Arcjet decision ArcjetDenyDecision {
  id: '', // This will contain the Arcjet request ID
  ttl: 0,
  results: [
    ArcjetRuleResult {
      ruleId: '',
      ttl: 0,
      state: 'RUN',
      conclusion: 'DENY',
      reason: [ArcjetSensitiveInfoReason]
    }
  ],
...
```

The default response for a request containing unexpected sensitive information
is a 400:

```sh
< HTTP/2 400
< content-type: application/json; charset=utf-8
< date: Tue, 09 Jan 2024 13:43:04 GMT
< vary: Accept-Encoding
< content-length: 72
```

The requests also appear in the [Arcjet dashboard](https://app.arcjet.com).
