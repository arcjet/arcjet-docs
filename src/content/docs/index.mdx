## Secure your agents

An AI agent that can send email, refund a payment, or write to a database needs
a security check at each of those boundaries. Arcjet covers the three questions
that follow, and you can start with any of them.

<CardGrid>
  <Link.Card
    title="Observe"
    href="/observe"
    description="Discover which agents run in your organization, with no code change. Send OpenTelemetry data to Arcjet or connect the Claude Compliance API."
  />
  <Link.Card
    title="Enforce"
    href="/guards/quick-start"
    description="Put an ALLOW or DENY decision in front of every tool call. Security teams change the policy centrally; developers own the enforcement point."
  />
  <Link.Card
    title="Audit"
    href="/audit"
