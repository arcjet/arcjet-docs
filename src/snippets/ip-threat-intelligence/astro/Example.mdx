Arcjet protection runs on HTTP requests. That is useful for dynamic routes in
Astro. It is not useful for static routes, which are pre-rendered at build time.

Astro uses
[middleware](https://docs.astro.build/en/guides/middleware/)
to intercept requests. That's where you add Arcjet.
