The **Detected by** column shows where Arcjet can detect each type:

- **SDK** means the SDK-local `sensitiveInfo` rule and the SDK-local detector in
  an agent guard policy, both of which run
  [Rampart](#on-device-detection-with-rampart) in your process. In the SDK,
  _model_ means the Rampart NER model detects the type, and _recognizer_ means
  a deterministic, validated pattern detects it. For example, card numbers must
  pass the Luhn checksum. Where the model and a recognizer overlap on the same
  text, the recognizer wins.
- **Server** means the server-side sensitive information detector in an agent
  guard or coding agent policy. For more information, see
  <Link.Page href="/guards/remote-policies#detectors">Detectors</Link.Page>.

The **Version** column shows the taxonomy version that added each type. The
version 2 types identify protected health information (PHI). For how versions
work, see
<Link.Page href="/guards/remote-policies#sensitive-information-taxonomy-versions">Sensitive information taxonomy versions</Link.Page>.
For how to detect PHI, see
<Link.Page href="/sensitive-info/phi">Detect protected health information (PHI)</Link.Page>.

Phone numbers are left to the model because their digit shape overlaps with
financial and government identifiers, so the default recognizers don't include
a phone number pattern. In the SDK, you can also detect your own types with
[custom entity detection](#custom-entity-detection).
