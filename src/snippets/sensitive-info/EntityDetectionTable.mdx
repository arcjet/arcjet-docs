**Model** means the on-device Rampart NER model detects the type. **Recognizer**
means a deterministic, validated pattern detects it – for example, card numbers
must pass the Luhn checksum. Where the model and a recognizer overlap on the
same text, the recognizer wins.

Phone numbers are left to the model because their digit shape overlaps with
financial and government identifiers, so the default recognizers don't include
a phone number pattern.
