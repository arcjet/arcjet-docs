Install the Guard SDK and LangChain extras:

```shell
pip install "arcjet[langchain-agents,sensitive-info-rampart]>=1.4.0" langchain langchain-openai
```

Or with [uv](https://docs.astral.sh/uv/):

```shell
uv add "arcjet[langchain-agents,sensitive-info-rampart]>=1.4.0" langchain langchain-openai
```
