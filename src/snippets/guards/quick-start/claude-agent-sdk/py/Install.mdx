<Aside type="note" title="This SDK runs the Claude Code CLI">
  `claude_agent_sdk` runs the Claude Code CLI as a subprocess. It ships a
  binary for most platforms, so `query()` works with nothing else installed.
  Where it doesn't, every `query()` call fails until `claude` is on your
  `PATH`:

  ```shell
  curl -fsSL https://claude.ai/install.sh | bash
  ```

  Or point at an install you already have with
  `ClaudeAgentOptions(cli_path="/path/to/claude")`.
</Aside>

```shell
pip install "arcjet[claude-agent-sdk,sensitive-info-rampart]"
```

Or with [uv](https://docs.astral.sh/uv/):

```shell
uv add "arcjet[claude-agent-sdk,sensitive-info-rampart]"
```
