Until `arcjet.guard.strands_agents` is published, pin `arcjet` to
`ADAPTER_SHA`. Published `arcjet` 1.0.0 on PyPI does not include
this extra.

```shell
pip install "arcjet[strands-agents,sensitive-info-rampart] @ git+https://github.com/arcjet/arcjet-py@ADAPTER_SHA"
```

Or with [uv](https://docs.astral.sh/uv/):

```shell
uv add "arcjet[strands-agents,sensitive-info-rampart] @ git+https://github.com/arcjet/arcjet-py@ADAPTER_SHA"
```
