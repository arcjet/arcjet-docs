### 4. Start server

```sh
go run .
```

Then make a `curl` request. You get a `403 Forbidden` response because `curl`
is considered an automated client by default. For more information about
allowing it, see
<Link.Page href="/bot-protection/identifying-bots">Identifying bots</Link.Page>.

```sh
curl -i http://localhost:8000
```
