### 4. Start server

```sh
go run .
```

Then make a `curl` request. You get a `403 Forbidden` response because `curl`
is considered an automated client by default. See
<Link.Page href="/bot-protection/reference">the reference guide</Link.Page> to
learn about configuring this.

```sh
curl -i http://localhost:8000
```
