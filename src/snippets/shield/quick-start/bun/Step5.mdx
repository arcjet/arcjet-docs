<Aside type="caution" title="This blocks your client">
  Running this simulation triggers Arcjet Shield and blocks your client for 15
  minutes. You can't configure this threshold or manage blocked clients.
</Aside>

```sh
curl -v -H "x-arcjet-suspicious: true" http://localhost:3000
```

The default response for a blocked request is a 403 Forbidden which you see when
you make the sixth request:

```sh
# ...5 requests made previously
curl -v -H "x-arcjet-suspicious: true" http://localhost:3000
...
```
