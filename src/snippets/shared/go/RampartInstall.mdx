Sensitive information detection runs on-device with the Rampart NER model.
Install the SDK and the Rampart module, which bundles the ~15&nbsp;MB of model
weights:

```sh
go get github.com/arcjet/arcjet-go
go get github.com/arcjet/arcjet-go/sensitiveinfo/rampart
```

Create the backend once at startup with `rampart.New` and reuse it. Loading
dequantizes the weights.
