In your project root, install the Arcjet Python SDK along with FastAPI and
Uvicorn. This example reads a form field, which FastAPI needs
`python-multipart` for:

```sh
uv add arcjet fastapi uvicorn python-multipart
```

If you don't use [uv](https://docs.astral.sh/uv/), `pip install arcjet fastapi
uvicorn python-multipart` (or your preferred package manager's equivalent)
works too.
