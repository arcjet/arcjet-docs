This example screens inbound user text for prompt injection before the model runs.

We assume you already have a TanStack AI project set up. For helper options and
denial behavior, see the <Link.Page href="/guards/tanstack-ai">TanStack AI agent guard</Link.Page>.

Install the dependencies:

```shell
# Export your Arcjet API key from https://console.arcjet.com
export ARCJET_KEY="ajkey_..."

npm install @arcjet/guard@git+https://github.com/arcjet/arcjet-js.git#3e81a91c5a97832b523305f2f7df281c12cf58d3 @tanstack/ai @tanstack/ai-openai zod
```

Requests appear in your [Arcjet dashboard](https://console.arcjet.com) in real time.
