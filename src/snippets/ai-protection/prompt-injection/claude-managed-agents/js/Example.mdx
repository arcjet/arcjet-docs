This example screens inbound user text for prompt injection before the model runs.

We assume you already have a Claude Managed Agents project set up. For helper options and
denial behavior, see the <Link.Page href="/guards/claude-managed-agents">Claude Managed Agents agent guard</Link.Page>.

Install the dependencies:

```shell
# Export your Arcjet API key from https://console.arcjet.com
export ARCJET_KEY="ajkey_..."

npm install @arcjet/guard@git+https://github.com/arcjet/arcjet-js.git#cb35c8f92c3a2fb63fbeb9b386d79b1878c19d92 @anthropic-ai/sdk
```
