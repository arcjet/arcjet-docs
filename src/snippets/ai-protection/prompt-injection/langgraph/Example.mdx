This example screens inbound user text for prompt injection before the model runs.

We assume you already have a LangGraph project set up. For helper options and
denial behavior, see the <Link.Page href="/guards/langgraph">LangGraph agent guard</Link.Page>.

Install the dependencies:

```shell
# Export your Arcjet API key from https://app.arcjet.com
export ARCJET_KEY="ajkey_..."

npm install @arcjet/guard @langchain/langgraph @langchain/core
```

Create the example:

<Code code={Step} lang="ts" title="agent.ts" />

Then start or invoke the agent with a test prompt.

Requests appear in your [Arcjet dashboard](https://app.arcjet.com) in real time.
