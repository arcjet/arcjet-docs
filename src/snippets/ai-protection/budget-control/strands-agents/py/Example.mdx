This example deducts an estimated token cost from a per-user bucket before a tool runs. When the bucket is empty, the tool does not execute.

We assume you already have a Strands Agents project set up. For helper options and
denial behavior, see the <Link.Page href="/guards/strands-agents">Strands Agents agent guard</Link.Page>.

Install the dependencies:

```shell
# Export your Arcjet API key from https://console.arcjet.com
export ARCJET_KEY="ajkey_..."
export ARCJET_ENV=development

pip install "arcjet[strands-agents] @ git+https://github.com/arcjet/arcjet-py@a630806169b92757192f3f5cce2e305827b26567"
```
