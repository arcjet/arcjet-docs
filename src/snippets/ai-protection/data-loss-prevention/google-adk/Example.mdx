This example scans a free-text tool argument for personal information before the tool executes. Detection runs locally. Don't pass opaque IDs such as an order number to the detector.

We assume you already have a Google ADK project set up. For helper options and
denial behavior, see the <Link.Page href="/guards/google-adk">Google ADK agent guard</Link.Page>.

Install the dependencies:

```shell
# Export your Arcjet API key from https://console.arcjet.com
export ARCJET_KEY="ajkey_..."

npm install @arcjet/guard@git+https://github.com/arcjet/arcjet-js.git#41ef36816e7174f1b0288d28217e63fa14114307 @google/adk zod
```
