Install the SDK and the Rampart backend:

```shell
go get github.com/arcjet/arcjet-go github.com/arcjet/arcjet-go/sensitiveinfo/rampart
```

Rampart runs on-device and detects email addresses, phone numbers, IP
addresses, card numbers, names, addresses, and government identifiers. For the
full list, see
<Link.Page href="/sensitive-info/reference#on-device-detection-with-rampart">On-device detection with Rampart</Link.Page>.
