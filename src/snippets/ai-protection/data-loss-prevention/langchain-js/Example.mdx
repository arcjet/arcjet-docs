This example scans a free-text tool argument before the tool runs.

We assume you already have a LangChain JS `createAgent` project set up. For
helper options and denial behavior, see the
<Link.Page href="/guards/langchain-js">LangChain JS agent guard</Link.Page>.

Until `@arcjet/guard/langchain/v1` is published, the import lives on
[`ce4051a6`](https://github.com/arcjet/arcjet-js/commit/ce4051a6fd70ac92d56d91713726a5796a32cd65),
not in the published `@arcjet/guard` package on npm.
`@arcjet/guard@1.10.0` does not export `./langchain/v1`.

Install the dependencies:

```shell
# Export your Arcjet API key from https://console.arcjet.com
export ARCJET_KEY="ajkey_..."

npm install @arcjet/guard langchain @langchain/core
```

Create the example:

<Code code={Step} lang="ts" title="agent.ts" />

Then start or invoke the agent with a test prompt.

Requests appear in your [Arcjet dashboard](https://console.arcjet.com) in real time.
