This example scans a free-text tool argument for personal information before the tool executes. Detection runs locally. Don't pass opaque IDs such as an order number to the detector.

We assume you already have a Genkit project set up. For helper options and
denial behavior, see the <Link.Page href="/guards/genkit">Genkit agent guard</Link.Page>.

Until `@arcjet/guard/genkit/v1` is published, the import lives on
[`f7619e4c`](https://github.com/arcjet/arcjet-js/commit/f7619e4c1c2a4f48a3342b7f8ab74a928ceb7309),
not in the published `@arcjet/guard` package on npm.

Install the dependencies:

```shell
# Export your Arcjet API key from https://console.arcjet.com
export ARCJET_KEY="ajkey_..."

npm install @arcjet/guard genkit
```

Create the example:

<Code code={Step} lang="ts" title="agent.ts" />

Then start or invoke the agent with a test prompt.

Requests appear in your [Arcjet dashboard](https://console.arcjet.com) in real time.
