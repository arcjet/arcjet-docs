## 4. Start app

```shell
python -c "import asyncio; from agent import run_agent; asyncio.run(run_agent(SESSION_ID, 'Look up order 1001'))"
```

Replace `SESSION_ID` with the Anthropic session `id` from
`sessions.create`. Don't mint an ID. Denied prompts and custom tool
calls appear in your
[Arcjet dashboard](https://console.arcjet.com) in real time.

For helper options, denial payloads, and correlation, see the
<Link.Page href="/guards/claude-managed-agents">Claude Managed Agents agent guard</Link.Page>.
