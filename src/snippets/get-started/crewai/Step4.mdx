## 4. Start app

```shell
python -c "from agent import run_crew; print(run_crew('Look up order 1001', '1001'))"
```

Then invoke the crew. Denied prompts and tool calls appear in your
[Arcjet dashboard](https://console.arcjet.com) in real time.
