## 4. Start app

```shell
npx tsx --env-file .env.local agent.ts
```

Then invoke the agent. Denied prompts and tool calls appear in your
[Arcjet dashboard](https://console.arcjet.com) in real time.

For helper options, denial payloads, and correlation, see the
<Link.Page href="/guards/strands-agents">Strands Agents agent guard</Link.Page>.
