## 4. Start app

```shell
python -c "import asyncio; from agent import run_agent; asyncio.run(run_agent('11111111-1111-4111-8111-111111111111', 'Look up order 1001'))"
```

Pass the caller-owned UUID `session_id` that you already have. Don't mint
one. Denied prompts and tool calls appear in your
[Arcjet dashboard](https://console.arcjet.com) in real time.

For helper options, denial payloads, and correlation, see the
<Link.Page href="/guards/claude-agent-sdk-py">Claude Agent SDK Python agent guard</Link.Page>.
