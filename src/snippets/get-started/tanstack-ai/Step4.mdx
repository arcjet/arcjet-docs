## 4. Start app

```shell
npx tsx --env-file .env.local agent.ts
```

Then invoke the agent. Denied tool calls appear on the
actor's **Activity** tab in the [Arcjet Console](https://console.arcjet.com) in
real time.

For helper options, denial payloads, and correlation, see the
<Link.Page href="/guards/tanstack-ai">TanStack AI agent guard</Link.Page>.
