## 4. Start app

```shell
go run .
```

That command compiles the wrapper. It does not start an agent or write a
dashboard event on its own. Hand the guarded tool to your agent and invoke
that agent. Denied tool calls appear in your
[Arcjet dashboard](https://console.arcjet.com) in real time.

For helper options, denial payloads, and correlation, see the
<Link.Page href="/guards/microsoft-agent-framework">Microsoft Agent Framework agent guard</Link.Page>.
