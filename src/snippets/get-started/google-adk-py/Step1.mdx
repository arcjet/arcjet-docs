Until `arcjet.guard.google_adk` is published, pin `arcjet` to
[`1e6e71cc`](https://github.com/arcjet/arcjet-py/commit/1e6e71cc70c8c98c1364fb0f88c7b09675715ec5).
Published `arcjet` 1.0.0 on PyPI does not include this extra.

```shell
pip install "arcjet[google-adk] @ git+https://github.com/arcjet/arcjet-py@1e6e71cc70c8c98c1364fb0f88c7b09675715ec5"
```

Or with [uv](https://docs.astral.sh/uv/):

```shell
uv add "arcjet[google-adk] @ git+https://github.com/arcjet/arcjet-py@1e6e71cc70c8c98c1364fb0f88c7b09675715ec5"
```
