This example screens inbound text with content moderation before the agent continues.

We assume you already have a Claude Agent SDK project set up. For helper options and
denial behavior, see the <Link.Page href="/guards/claude-agent-sdk">Claude Agent SDK agent guard</Link.Page>.

Install the dependencies:

```shell
# Export your Arcjet API key from https://app.arcjet.com
export ARCJET_KEY="ajkey_..."

npm install @arcjet/guard @anthropic-ai/claude-agent-sdk
```
