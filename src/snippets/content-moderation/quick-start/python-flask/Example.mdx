This example screens inbound text with content moderation before you store or
display it.

Content moderation is a Guard rule, so this example uses `arcjet.guard` inside
your Flask route – not `protect()`. Use `launch_arcjet_sync` with
`guard_sync()` in sync Flask code.

We assume you already have a Flask project set up. For helper options and
denial behavior, see the <Link.Page href="/guards">Agent guards</Link.Page>
guide.

Install the dependencies:

```shell
# Export your Arcjet API key from https://console.arcjet.com
export ARCJET_KEY="ajkey_..."
export ARCJET_ENV=development

pip install arcjet flask
```

Then send a test `POST` request to `/messages`.

Requests appear in your [Arcjet dashboard](https://console.arcjet.com) in real time.
