This example screens inbound text with content moderation before you store or
display it.

Content moderation is a Guard rule, so this example uses `@arcjet/guard` inside
your Remix action – not `protect()`.

We assume you already have a Remix project set up. For helper options and
denial behavior, see the <Link.Page href="/guards">Agent guards</Link.Page>
guide.

Install the dependencies:

```shell
# Export your Arcjet API key from https://app.arcjet.com
export ARCJET_KEY="ajkey_..."

npm install @arcjet/guard
```

Create the example:

<Code code={Step} lang="ts" title="app/routes/messages.ts" />

Then send a test `POST` request to the route.

Requests appear in your [Arcjet dashboard](https://app.arcjet.com) in real time.
