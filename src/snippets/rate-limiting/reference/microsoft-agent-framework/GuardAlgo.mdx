Guard rate limits in the Go SDK include `GuardTokenBucket`,
`GuardFixedWindow`, and `GuardSlidingWindow`. Set `Capacity` to the burst
you want and `RefillRate` / `Interval` to the sustained allowance. `Interval`
is a `time.Duration`.

For a complete tool example, see the token bucket example on this page. For more
information about adapter options, see the
<Link.Page href="/guards/microsoft-agent-framework">Microsoft Agent Framework agent guard</Link.Page>.
